# Internship Tracker Web App
A clean and simple Internship Tracker bulit using HTML, CSS and JavaScript. 

#Features: 
-You can add company name, role you've applied for, application date and the status of the internship. 
-You can view submitted applications in a dynamic table.
-The form automatically resets after clicking on 'Add Application'.

#Tech Stack:
-HTML
-CSS
-JavaScript

#How to Use: 
-Open the index.html file in any browser.
-Fill in the required information and click 'Add Application.'
-You can view your enteries appear in the table below. 

#Limitations:
*This version does not use constant storage, thus, the data resets with every browser refresh. 
*A version with LocalStorage support is currently being developed.
